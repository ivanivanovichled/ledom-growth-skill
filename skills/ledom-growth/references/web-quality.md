# Техническое качество: измерить, исправить, сравнить

## Доказательство проблемы

Для доступного URL сначала искать полевые данные CrUX/GSC либо согласованный RUM. Различать данные страницы и всего origin; отсутствие данных не означает плохую скорость. Затем получить лабораторный замер/трассу для диагностики, записав устройство, URL, сеть/CPU, дату и состояние страницы. Единичный Lighthouse/PSI балл не является полевым результатом и не доказывает рост обращений.

LCP диагностировать по фактическому элементу и задержкам его обнаружения/загрузки/отрисовки; INP — по наблюдаемому взаимодействию и работе main thread; CLS — по конкретному сдвигу и его причине. Актуальные пороги и методы проверять по https://web.dev/articles/vitals ; не измерять INP выдуманным числом по одному статическому HTML.

## Реальные рычаги Tilda

Проверять размеры/форматы изображений, первый экран, загрузку шрифтов, лишние виджеты/анимации и сторонние скрипты. Тяжёлую обложку оптимизировать с сохранением качества. Не откладывать загрузку главного изображения без измерения; preload добавлять, только когда видна задержка обнаружения, и без дублирования запросов.

Не удалять Метрику, согласия, форму или библиотеку Tilda ради балла. Перед правкой head/CSS проверить исходное содержимое, область действия и доступный MCP. Исправления CDN/сервера/framework применять лишь при реальном контроле; не предлагать перенос сайта как автоматическое решение.

Проверить сохранение места изображениям/динамическим блокам, загрузку реальных фирменных шрифтов, мобильные кнопки/меню, отображение формы и взаимодействие с согласиями. Для доступности: смысловые заголовки, названия полей/кнопок, видимый фокус, доступ с клавиатуры, контраст, содержательные alt. Декоративным изображениям уместен пустой alt, если это не несущая информацию иллюстрация статьи.

## Проверка исправления

Повторить сопоставимый лабораторный замер и тот же пользовательский сценарий. Сохранить до/после, область изменений, возможные побочные эффекты. Проверить фактическую страницу на трёх ширинах по `tilda-release.md`.

Не заявлять немедленное улучшение полевого p75: нужны новые реальные визиты и обновление окна данных. Не запускать бесконечные повторные PSI-замеры ради случайного значения 90+. Остановиться после достаточного подтверждения нужной правки; новые замеры обоснованы изменением, ошибкой или конкретной неопределённостью.
