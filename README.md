# LEDO.М Growth

Один русскоязычный Agent Skill для продвижения премиального ремонта в Москве и Московской области. Каталог навыка: [`skills/ledom-growth`](skills/ledom-growth/SKILL.md). Версия 1.0.0.

Внутри: SEO Яндекс/Google, контент и конверсия, Tilda, локальное продвижение Яндекс/2ГИС/Google, аналитика обращений, партнёрства, поиск площадок и индивидуальные email-запросы условий размещения. Подробности подгружаются по задаче; отдельные upstream-навыки устанавливать не нужно.

## Установка в Codex

После скачивания/клонирования репозитория запустить из его корня:

```powershell
.\scripts\install.ps1
```

Установщик копирует только `skills/ledom-growth` в `$CODEX_HOME/skills/ledom-growth` или, если переменная не задана, в `~/.codex/skills/ledom-growth`. Не подключает сервисы, не требует токенов и не запускает сторонние скрипты. При существующей отличающейся версии останавливается; явный `-Update` сохраняет резервную копию перед заменой. Одинаковая версия лишь сверяется.

Навык будет доступен на следующем ходе. Пример:

```text
Используй $ledom-growth для аудита существующей страницы услуги LEDO.М.
```

Другие примеры задач:
- Сверить существующие статьи и найти самостоятельные темы с коммерческим смыслом.
- Проверить карточки Яндекс Бизнеса и 2ГИС и подготовить конкретные исправления.
- Найти релевантные площадки для выбранного URL и направить индивидуальные запросы условий размещения.
- Разобрать органические обращения и причины потерь в воронке.

## Как он работает

Навык читает актуальные `AGENTS.md`, планы и журналы рабочего проекта, а не закрепляет старые цены/состояния. В публичном пакете нет почтовой базы, статистики аккаунтов, фотографий, ключей или доступов. Для другого workspace надо предоставить его собственный контекст; навыком не выдаются права представлять LEDO.М.

Операции Tilda выполняются через доступный официальный MCP с чтением текущих схем; браузер используется для реального рендера и отсутствующих функций. Почтовая отправка нужна только в явно порученной кампании. Цена, договор и оплата согласуются отдельно от запроса условий. Установка сама ничего не отправляет и не публикует.

Отдельные API-подписки не обязательны. Без подключённых кабинетов доступны исследование и подготовка; результаты интеграций не имитируются. Python 3.10+ нужен только для необязательного локального `funnel_report.py` и проверки пакета. Сам навык состоит из Markdown/YAML/CSV/JSON.

## Проверка

```powershell
python .\scripts\validate_package.py
python -m unittest discover -s .\tests -v
```

`validate_package.py` проверяет ссылки ресурсов, состав пакета, сохранённые лицензии и закрепление upstream. Он не доказывает рост трафика или доступность кабинетов. Для стандартной проверки frontmatter можно дополнительно выполнить системный Codex `skill-creator/scripts/quick_validate.py`.
